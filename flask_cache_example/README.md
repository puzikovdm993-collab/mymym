# Flask AppCache Example

Пример веб-приложения на Flask с офлайн-режимом через **HTML5 AppCache** (без Service Worker).

## Особенности

- Работает на любом домене (не только localhost)
- Не требует HTTPS (в отличие от Service Worker)
- Кэширует HTML, CSS и JS файлы
- Страница продолжает работать при выключенном сервере

## Структура проекта

```
flask_cache_example/
├── app.py              # Сервер Flask
├── static/
│   ├── index.html      # Главная страница (с manifest атрибутом)
│   ├── cache.manifest  # Файл манифеста кэша
│   ├── style.css       # Стили
│   └── script.js       # Клиентский JavaScript
└── README.md
```

## Запуск

```bash
cd /workspace/flask_cache_example
python app.py
```

Сервер запустится на http://127.0.0.1:5000

## Как это работает

1. При первом посещении страницы браузер загружает `cache.manifest`
2. Браузер кэширует все файлы, указанные в манифесте
3. При обновлении страницы (F5) браузер использует кэшированную версию
4. При выключенном сервере страница продолжает работать из кэша

## Обновление кэша

Чтобы обновить кэш у пользователей:
1. Измените комментарий с версией в файле `cache.manifest`
2. Браузер обнаружит изменение и загрузит новую версию

## Проверка офлайн-режима

1. Откройте страницу в браузере
2. Дождитесь сообщения "Страница закэширована!"
3. Выключите сервер (Ctrl+C)
4. Обновите страницу (F5) - она продолжит работать!

## Примечания

- AppCache работает в большинстве современных браузеров
- Для работы требуется первый заход на страницу при включенном сервере
- Файл манифеста должен отдаваться с MIME-типом `text/cache-manifest`
