# Пример кэширования HTML, CSS и JS в браузере с Flask

Этот проект демонстрирует, как настроить сервер на Flask для отдачи файлов с правильными заголовками кэширования, чтобы браузер мог сохранять их в кэш.

## Структура проекта

```
flask_cache_example/
├── app.py              # Сервер Flask
└── static/             # Статические файлы
    ├── index.html      # HTML страница
    ├── style.css       # Стили
    └── script.js       # JavaScript
```

## Как это работает

### Заголовки кэширования

Сервер устанавливает следующие заголовки для разных типов файлов:

1. **HTML** (`index.html`):
   - `Cache-Control: public, max-age=3600` - кэшируется на 1 час
   - `ETag: "html-v1"` - версия для проверки изменений

2. **CSS** (`style.css`):
   - `Cache-Control: public, max-age=31536000` - кэшируется на 1 год
   - `ETag` - автоматически генерируется по содержимому файла

3. **JavaScript** (`script.js`):
   - `Cache-Control: public, max-age=31536000` - кэшируется на 1 год
   - `ETag` - автоматически генерируется по содержимому файла

### Поведение браузера

1. **Первый визит**: Все файлы загружаются с сервера
2. **Обновление страницы (F5)**: 
   - Браузер проверяет кэш
   - Если файл есть в кэше и не истек срок - загружается из кэша
   - Если истек срок - отправляется запрос с `If-None-Match` для проверки ETag
   - Если файл не изменился - сервер возвращает `304 Not Modified`

## Запуск

```bash
cd /workspace/flask_cache_example
python app.py
```

Сервер запустится на `http://127.0.0.1:5000`

## Проверка кэширования

1. Откройте `http://127.0.0.1:5000` в браузере
2. Откройте DevTools (F12) → вкладка Network
3. Обновите страницу (F5)
4. Обратите внимание на столбец "Size":
   - `(memory cache)` или `(disk cache)` - файл загружен из кэша
   - Размер в байтах - файл загружен с сервера

## Особенности реализации

- Используется `send_from_directory()` с параметром `max_age` для установки заголовков кэширования
- Для HTML установлен меньший срок кэширования (1 час), так как он может часто меняться
- Для CSS и JS установлен длительный срок кэширования (1 год)
- При изменении файлов рекомендуется менять их имена (например, `style.v2.css`) или версию в ETag
