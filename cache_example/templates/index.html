Демонстрация кэширования в браузере

Как это работает:

  • HTML страница - не кэшируется (или кэшируется на короткое время), чтобы браузер всегда загружал актуальную версию с сервера
  • CSS и JS файлы - кэшируются на 1 год с заголовком immutable, что означает, что браузер будет загружать их из кэша при обновлении страницы (F5)

Проверка работы:

  1. Откройте инструменты разработчика (F12)
  2. Перейдите на вкладку Network (Сеть)
  3. Обновите страницу (F5)
  4. Вы увидите, что:
    • HTML файл загружается с сервера (статус 200 или 304)
    • CSS и JS файлы загружаются из кэша (статус 200 (from cache) или 304 Not Modified)
