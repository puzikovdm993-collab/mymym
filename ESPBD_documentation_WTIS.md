# Комплект программной документации WTIS по стандартам ЕСПД

**Объект документирования:** веб-приложение **WTIS — Web-based Tomograph Instrumental System** (репозиторий `/workspace`, коммит `065a927`).

**Нормативная база:** стандарты ЕСПД (ГОСТ 19.101–19.801). Основной источник требований к комплектности и правилам применения — https://www.swrit.ru/gost-espd.html . Действующих «новых редакций» базовых стандартов серии 19 не выпускалось; применяются издания 1978–1981 гг. в действующей редакции: ГОСТ 19.201-78 (ТЗ), 19.204-78 (ПМИ), 19.402-80 (ОП), 19.401-79 (ТП), 19.505-79 (РО/РП), 19.502-78 (РСП), 19.503-79 (ВД, ФО). Оформление текстов — по ГОСТ 2.105-95. Если требования старой и действующей практики отличаются, это указано в разделе «Состав документации».

**Принцип:** всё описанное подтверждено исходным кодом. Недоказуемые сведения помечены **[ТУ]** (= требует уточнения). Ничего не додумано.

### 3.3. Ключевые алгоритмы (Этап 6)

1. **Медианный фильтр `_medianFilter`** — вход: matrix, апертура r; паддинг краями → скользящее окно (2r+1)² → сортировка → медиана → новая матрица; ошибка: нет активного файла (alert).
2. **Коррекция фона** — `_computePolynomialCoefficients` (базис полиномов порядка k, система нормальных уравнений МНК) + `_solveGaussianElimination` (прямой/обратный ход) → вычитание фона.
3. **imageToMatrix** — ImageData → нормализация `(v-min)/(max-min)` → обратное картирование.
4. **Лассо** — сбор точек мышью → замыкание контура → маска выделения → bbox.
5. **Профиль** — линия p1–p2, растеризация отрезка (`bresenham()`), клиппинг (`clipLine`), выборка значений.
6. **История undo/redo** — `pushState` (усечение redo-ветви, лимит 20) → асинхронно `updateHistoryFile` (POST истории).
7. **Исполнение графа workflow** — последовательный обход LiteGraph, каждый узел `onExecute` передаёт `{matrix,w,h,min,max,dpi,colormap}` по связям.

Блок-схемы в ОП оформлены как пронумерованные последовательности операций с ветвлением обработки ошибок.
